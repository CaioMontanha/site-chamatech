# Glossário de identificadores

| Original | Português |
| --- | --- |
| `Page` | `Pagina` |
| `RootLayout` | `LayoutRaiz` |
| `Stat` | `Indicador` |
| `Status` (tipo local) | `Estado` |
| `logoUrl` | `urlLogotipo` |
| `supabaseUrl` | `urlSupabase` |
| `supabaseKey` | `chaveSupabase` |
| `supabase` (instância local) | `clienteSupabase` |
| `supabaseConfiguracaoIncompleta` | `configuracaoSupabaseIncompleta` |
| `progressoPorStatus` | `progressoPorEstado` |
| `authPronta` | `autenticacaoPronta` |
| `mensagemAuth` | `mensagemAutenticacao` |
| `atualizarStatus` | `atualizarEstado` |
| `event` (parâmetro local) | `evento` |
| `password` (variável local) | `senha` |
| `icon`, `label`, `value`, `helper` (propriedades do indicador local) | `icone`, `rotulo`, `valor`, `ajuda` |
| `item` (parâmetro local) | `chamado` |
| `week`, `start`, `end`, `group`, `percentage` | `semana`, `inicio`, `fim`, `grupo`, `percentual` |
| `Button` (componente local) | `Botao` |
| `buttonVariants` | `variantesBotao` |
| `cn` | `combinarClasses` |
| `components` (diretório) | `componentes` |
| `ui` (diretório) | `interface` |
| `button.tsx` | `botao.tsx` |
| `lib` (diretório) | `biblioteca` |
| `utils.ts` | `utilitarios.ts` |
| `nextConfig` | `configuracaoNext` |
| `config` (variável local) | `configuracao` |

Campos persistidos no Supabase, variáveis de ambiente, nomes de pacotes, APIs do React/Next/Supabase, propriedades HTML, variante `icon` do botão e nomes de arquivos exigidos pelo Next.js permanecem conforme seus contratos.
